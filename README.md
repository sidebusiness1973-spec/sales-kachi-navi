# 営業マン勝ちナビ

顧客・架電・商談の記録をまとめて、次の営業活動につなげるアプリです。

## アプリを入手

[iPhone・iPad・Mac版をApp Storeで確認する](https://apps.apple.com/jp/app/id6816914462)

対応機種と動作条件はApp Storeの表示をご確認ください。

## できること

- 顧客情報と営業段階を管理
- 架電・商談などの活動を記録
- 活動件数をダッシュボードで確認
- フォロー予定を整理
- 営業トークを記録・参照

## 更新について

ホーム画面・カード・端末別アイコンを改善した更新版を準備しています。iOS・Macの更新ビルドはアップロード済みです。掲載画像の更新と審査提出は準備中です。
